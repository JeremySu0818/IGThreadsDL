# Translation catalog

`strings.json` is the source of app UI, floating tool, notification, login,
permission, resolver, and download messages. Its top-level keys are the 20
`AppLanguage.code` values (including `pt-br`, `zh-cn`, and `zh-tw`). Each value
is a flat object whose keys match the typed `AppStrings` properties.

Edit the translated value in the appropriate language object. Preserve Java
format placeholders such as `%1$d` and `%2$s`; JSON uses literal `$` characters.
Keep the English (`en`) object complete: missing, blank, or non-string translated
values, and missing language objects, fall back to English at runtime.

Android `res/values*/strings.xml` remains available for labels used by the OS.
App language selection is saved in `app_settings/app_language`. The System
option follows the device locale; unsupported device languages use English.
Arabic uses RTL layouts. Chinese script tags take precedence over region tags.

Validate the catalog and build:

```sh
./gradlew :app:testDebugUnitTest :app:assembleDebug
```
